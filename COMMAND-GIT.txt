ده عشان اعرف مين الى اكسس او عمل اى اكشن
------------------------------------------------------------------------------------------------------------------------------
انا عملت add file on stage عاوز ارجعه للdevolleper يعدل فيه
$git rm --cached file1.txt
$git add file1.txt
$git commit -m "message"
------------------------------------------------------------------------------------------------------------------------------
لو عاوز اعرف الفرق مابيت التعديل ده وده
$git diff (الكود الى موجود بعد امر log)
------------------------------------------------------------------------------------------------------------------------------
$rm file1.txt      انا مسحت الفايل
$git restore file1.txt   ده بيعملى restore
------------------------------------------------------------------------------------------------------------------------------
$git reset code --hard           ده لو انا عاوز ارجع للفايل من الاول من قبل التغيير ده
------------------------------------------------------------------------------------------------------------------------------
$git commit -am            ده لو عاوز اسكيب خطوه add واعمل commit بس الفايل يكون متعدل فيه مش جديد
------------------------------------------------------------------------------------------------------------------------------
$git branch     لو عاوز اعرف عندى كاك branch

$git branch new-branch        لو عاوز اكريت برانش جديد
$git switch new-branch        لو عاوز اخش على البرانش الجديد
$git merge new-branch                             لو عاوز اعمل ميرج لبرانش بس لزما ارجع للماستر
$git branch -r new-branch                    لو عاوز امسح البرانش
